# 🌤 Weather Pro

A beautiful, fully-featured weather application built with pure **HTML, CSS & JavaScript**.

Real-time weather • 5-day forecast • Hourly outlook • Favorites • Dark mode • °C/°F • Geolocation

---

## ✨ Features

### Weather Data
- Current temperature, feels-like, high/low
- Humidity, wind speed, pressure, visibility
- Sunrise & sunset times
- Dynamic weather icons (OpenWeather)
- Weather-based animated backgrounds

### Forecast
- **Next 24 hours** hourly forecast
- **5-day** daily forecast with high/low

### Smart Features
- Search any city worldwide
- Current location (Geolocation API)
- Recent search history (persistent)
- Favorite cities with one-click access
- °C / °F unit toggle
- Dark / Light theme
- Offline detection & recovery
- Last searched city auto-loads

### UI / UX
- Modern glassmorphism design
- Smooth animations & skeleton loading
- Fully responsive (mobile → desktop)
- Clean, accessible interface

---

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom properties, glassmorphism, responsive)
- Vanilla JavaScript (ES6+, Fetch, LocalStorage, Geolocation)
- [OpenWeatherMap API](https://openweathermap.org/api)

---

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in a modern browser  
   *(or use Live Server in VS Code)*

That’s it — no build step required.

### API Key

The app already includes a working OpenWeatherMap API key for demonstration.  
For production use, create your own free key at [openweathermap.org](https://openweathermap.org/api) and replace it in `script.js`:

```js
apiKey: "YOUR_API_KEY"
```
